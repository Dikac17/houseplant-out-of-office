An out-of-office auto-reply written as a houseplant for make.fun's "The Houseplant Out-of-Office" bounty: a program (Node 22, stdlib only) that writes a single 100-character reply to `/output/entry.txt`. No network, deterministic — the same bytes on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
